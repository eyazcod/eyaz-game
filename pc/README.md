# مغامرات إياز — Eyaz Adventures

مشروع نسخة الكمبيوتر، مبني على Godot 4.7.2. افتح `project.godot` ثم شغّل المشروع.

## آخر التحديثات

- واجهة عربية وإنجليزية، مع حفظ اللغة والتقدم تلقائيًا.
- قائمة رئيسية بنيران بيكسل متحركة وموسيقى أصلية.
- جزر موزعة عشوائيًا فوق بحر حمم، وسفينة تبحر للمراحل المفتوحة.
- بطاقة دخول لكل جزيرة تعرض حارسها وقدرات اللاعب.
- واجهة بيكسل للصحة والطاقة والذخيرة والقنابل؛ تنبيه الالتقاط بالأنميشن.
- 20 طلقة عند بدء الجزيرة، وأعداء وزعماء أقوى.
- حذف شيك بوينت البوس؛ انتهاء الأرواح يعيد نفس الجزيرة من البداية.
- دعم الكيبورد ويدات التحكم، ملء الشاشة، وإخفاء الماوس أثناء اللعب.
- Discord Rich Presence اختياري عبر مساعد محلي مبني من C#.

## الخطوط

حمّل الخطوط من [المصدر الرسمي لثمانية](https://font.thmanyah.com/) وضع الملفات التالية في `assets/`:

- `thmanyahsans-Medium.otf`
- `thmanyahserifdisplay-Bold.otf`
- `thmanyahseriftext-Medium.otf`

لا يتضمن المستودع ملفات الخط الخام. يعمل المشروع بخط نظام بديل عند عدم إضافتها. راجع ترخيص ثمانية قبل توزيع الخط مع أي منتج.

## تصدير Windows

ثبّت Godot 4.7.2 وقوالب التصدير المطابقة، ثم شغّل من PowerShell:

```powershell
./build.ps1 -Godot "C:/path/to/Godot.exe"
```

الناتج: `build/EYAZ-Game.exe`. يقوم السكربت ببناء مساعد Discord إن توفر مترجم .NET Framework على Windows. لا يحتاج التطبيق إلى Bot Token أو أي كلمة مرور. لا يتضمن المصدر مفاتيح توقيع أندرويد أو بيانات المستخدم.

## الاختبارات

```powershell
godot --headless --path . --quit-after 900 -- --smoke-test
```

تتحقق الاختبارات من المراحل العشر، القتال، التحكم، الحفظ، إزالة شيك بوينت البوس وإعادة الجزيرة عند انتهاء الأرواح. يستخدم الاختبار ملف حفظ منفصلًا.
