# مغامرات إياز — Eyaz Adventures

لعبة مغامرات ومنصات بيكسل: استكشف واجمع المعادن عبر عشر جزر وحارب حراسها.

## نسخة الكمبيوتر — Godot

المشروع المحدّث في [`pc/`](pc/). يحتوي على واجهة عربية وإنجليزية، خريطة جزر عائمة فوق الحمم، سفينة للتنقل، ودعم يد التحكم.

- [طريقة التشغيل والبناء](pc/README.md)
- [آخر التحديثات](CHANGELOG.md)

افتح `pc/project.godot` باستخدام Godot 4.7.2. تتوفر تعليمات إضافة خط ثمانية وبناء نسخة Windows في دليل المشروع.

## نسخة المتصفح

النسخة الأصلية موجودة في [`index.html`](index.html) ويمكن تشغيلها عبر [GitHub Pages](https://eyazcod.github.io/eyaz-game/). تطوير واجهة الكمبيوتر الأخير موجود في مشروع Godot.
